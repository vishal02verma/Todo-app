# Todo-list

A Flutter todo app for keeping everyday tasks organized.

## Features

- Add tasks with a title, optional description, and priority.
- Edit, complete, and delete tasks.
- Search tasks and filter by all, pending, or completed.
- View total, completed, and pending task counts.
- Save tasks locally on the device between app launches.

## Run

Install [Flutter](https://docs.flutter.dev/get-started/install), then run:

```sh
flutter pub get
flutter run
```

## Test

```sh
flutter test
```
